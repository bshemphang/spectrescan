# SpectreScan — app

This is the Next.js 16 app for SpectreScan (Kiroween 2026, Frankenstein
category). The project README lives at the repo root:
[`../README.md`](../README.md).

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm test           # unit + property tests
npm run test:fixtures   # live scans of SELO / AGIO / CAKE
npm run typecheck
```

No environment variables, no API keys, no wallet, no sign-in.
