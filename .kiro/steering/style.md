# Steering — Style

Applies to all UI and copy in this project.

- One accent colour only: spectral violet (#a78bfa). Background near-black
  (#0c0a12), text bone-white (#f2f0ea).
- Typography: Fraunces for display headings, Inter for body. No more than
  two font families.
- No emoji anywhere in the UI. Use Lucide icons only.
- Copy must be specific and real: name the actual check, the actual value,
  the actual line. No filler ("cutting-edge", "revolutionary", "next-gen").
- Every finding card shows: severity, plain-English title, one-sentence
  explanation, and its evidence (file:line or on-chain value).
- Mobile layout must be as good as desktop: the ghost meter stacks above
  the findings, nothing overflows, buttons are thumb-sized.
